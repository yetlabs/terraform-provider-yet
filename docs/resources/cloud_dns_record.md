# Resource: yet_cloud_dns_record

One name's values of one type in a zone. The records Cloud keeps for environments are its own; these are the company's.

## Example Usage

```terraform
resource "yet_cloud_dns_record" "mx" {
  zone_id = yet_cloud_dns_zone.acme.id
  name    = "@"
  type    = "MX"
  ttl     = 3600
  values  = ["10 mx1.acme.dev", "20 mx2.acme.dev"]
}
```
