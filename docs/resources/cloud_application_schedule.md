# Resource: yet_cloud_application_schedule

A path of an application's called on a cron, on its stages: on a runtime a CronJob beside it, which asks its own Service; on Lambda, EventBridge Scheduler in the account calling its function straight — up to its `timeout_seconds`. The application gets a request, `X-Yet-Schedule` the schedule's name and `X-Yet-Schedule-Token` what it is handed as `YET_SCHEDULE_TOKEN` — check it: one without it is anyone's. A status from 400 fails the run. One at a time on a runtime: a run still going when the next is due, the next waits.

## Example Usage

```terraform
# Every minute, on every stage: a POST to the application's own path — on a
# runtime from a CronJob beside it, on Lambda from EventBridge Scheduler.
resource "yet_cloud_application_schedule" "reconcile" {
  application_id = yet_cloud_application.api.id
  name           = "reconcile"
  cron           = "* * * * *"
  path           = "/api/cron/reconcile"
}

# At three on weekdays, in São Paulo's time, on production alone.
resource "yet_cloud_application_schedule" "nightly" {
  application_id = yet_cloud_application.api.id
  name           = "nightly"
  cron           = "0 3 * * 1-5"
  time_zone      = "America/Sao_Paulo"
  method         = "GET"
  path           = "/jobs/nightly?full=1"
  stages         = [yet_cloud_environment.production.id]
}
```

## Schema

### Required

- `application_id` (String) The application (`yet_cloud_application`'s `id`).
- `cron` (String) When: five fields — minute, hour, day of the month, month, weekday — a day of the month or a weekday, not both. `*/5 * * * *` is every five minutes; `0 3 * * 1-5`, at three on weekdays.
- `name` (String) Its name, the application's only one so named: lowercase letters, digits and dashes, up to 40.
- `path` (String) What it calls, from `/`: `/api/cron/reconcile`, a query too.

### Optional

- `method` (String) `GET`, `POST`, `PUT`, `PATCH` or `DELETE`; `POST` when left out.
- `stages` (Set of String) The application's stages it runs on, by environment id; every one when left out.
- `time_zone` (String) The cron's time zone, as the tz database names it — `America/Sao_Paulo`; UTC when left out.

### Read-Only

- `id` (String) The ID of this resource.
