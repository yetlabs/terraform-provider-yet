# Resource: yet_settings_aws_account

One of the company's AWS accounts, for some of Yet's products: Mail's own SES, Drive's documents, Cloud's databases' copies — each of those one account's. Its `external_id` is what its stack is made with; `yet_settings_aws_account_role` connects it.

!> **Warning:** Destroying it forgets the account: what it was for stops. Its stack stays in AWS.

## Example Usage

```terraform
# The production account, for Mail's SES, Drive's documents and Cloud's copies:
# added to Yet, its stack made with the AWS provider, its role handed back.
data "yet_settings_aws_launch" "yet" {}

resource "yet_settings_aws_account" "production" {
  name   = "Production"
  region = "us-east-1"
  uses   = ["mail", "drive", "databases"]
}

resource "aws_cloudformation_stack" "yet" {
  name         = "yet-acme-production"
  template_url = data.yet_settings_aws_launch.yet.template_url
  capabilities = ["CAPABILITY_IAM"]
  parameters = {
    YetPrincipal = data.yet_settings_aws_launch.yet.principal
    ExternalId   = yet_settings_aws_account.production.external_id
    Company      = "acme"
    UseMail      = "true"
    UseDrive     = "true"
    UseDatabases = "true"
  }
}

resource "yet_settings_aws_account_role" "production" {
  account_id = yet_settings_aws_account.production.id
  role_arn   = aws_cloudformation_stack.yet.outputs["RoleArn"]
}

# An account for its applications' buckets, named as the company names them:
# the stack lets Yet make and set up only buckets beginning vinilo-.
resource "yet_settings_aws_account" "media" {
  name          = "Media"
  region        = "sa-east-1"
  uses          = ["applications"]
  bucket_prefix = "vinilo-"
}

resource "aws_cloudformation_stack" "media" {
  name         = "yet-acme-media"
  template_url = data.yet_settings_aws_launch.yet.template_url
  capabilities = ["CAPABILITY_IAM"]
  parameters = {
    YetPrincipal             = data.yet_settings_aws_launch.yet.principal
    ExternalId               = yet_settings_aws_account.media.external_id
    Company                  = "acme"
    UseApplications          = "true"
    ApplicationsBucketPrefix = yet_settings_aws_account.media.bucket_prefix
  }
}
```

## Schema

### Required

- `name` (String) Its name, as Settings shows it: `Production`.
- `region` (String) Where its stack runs, and its SES sends from: `us-east-1`.
- `uses` (Set of String) What it is for: `mail`, `drive`, `databases`, `vault` — connected, it takes those from any other account — and `servers`, Cloud's EC2 instances, and `applications`, its applications' S3 buckets, which any account may be for.

### Optional

- `bucket_prefix` (String) What its applications' buckets begin with — its stack's `ApplicationsBucketPrefix`, set in the stack too: empty, `yet-<company>-`; `*` any name, which lets Yet set up any bucket of the account.

### Read-Only

- `external_id` (String, Sensitive) Its external ID: its stack's `ExternalId`.
- `id` (String) Its id in Yet.
