# Resource: yet_settings_storage

Where Drive keeps the company's files: a bucket in its own AWS account, reached with `yet_settings_connection_aws`'s role. Yet writes to it once, and removes what it wrote, to be sure the role may use it — the stack makes one, set when the account connects; another of the company's goes in the stack as its `ExistingDriveBucket`.

~> **Note:** Destroying it sends Drive back to keeping the files itself. The bucket, and what is in it, stay in the company's account.

## Example Usage

```terraform
# Drive's files in the company's own bucket, under yet/drive.
resource "yet_settings_storage" "acme" {
  bucket = "acme-drive"
  prefix = "yet/drive"

  depends_on = [yet_settings_connection_aws.acme]
}
```
