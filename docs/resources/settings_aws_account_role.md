# Resource: yet_settings_aws_account_role

The role an AWS account's stack made, handed to Yet: assumed and checked with AWS before it is kept. Connected, the account takes what it is for from any other.

-> **Note:** Destroying it leaves the account connected; destroying `yet_settings_aws_account` forgets it.

## Example Usage

```terraform
# The role a staging account's stack made, handed to Yet.
resource "yet_settings_aws_account_role" "staging" {
  account_id = yet_settings_aws_account.staging.id
  role_arn   = "arn:aws:iam::123456789013:role/yet-acme-staging-Role-1A2B3C4D5E6F"
}
```
