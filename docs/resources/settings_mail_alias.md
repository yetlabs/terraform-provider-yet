# Resource: yet_settings_mail_alias

Another address for someone of the company: `contato@` landing in Ana's inbox. It is at the person's own domain.

-> **Note:** Mail to the alias goes on arriving in the person's mailbox until it is destroyed; destroying it bounces what comes after.

## Example Usage

```terraform
# contato@acme.dev, landing in Ana's inbox.
resource "yet_settings_mail_alias" "contact" {
  person_id = yet_settings_person.ana.id
  name      = "contato"
}
```

## Schema

### Required

- `name` (String) The alias before the @: `contato`.
- `person_id` (String) Whose inbox it lands in: a `yet_settings_person`'s `id`.

### Read-Only

- `address` (String) The whole alias: `contato@acme.dev`.
- `domain` (String) The person's domain, where the alias is.
- `id` (String) `<person_id>/<name>`.
