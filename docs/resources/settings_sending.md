# Resource: yet_settings_sending

How the company's mail leaves: through Yet's SES, or the SES of its own AWS account (`yet_settings_connection_aws`). Switching moves every domain with mail to the other SES.

~> **Note:** There is one per company: creating this resource takes hold of it, and destroying it leaves the choice as it is.

## Example Usage

```terraform
# Through the SES of the company's own AWS account.
resource "yet_settings_sending" "acme" {
  sending = "own"

  depends_on = [yet_settings_connection_aws.acme]
}
```

## Schema

### Required

- `sending` (String) `yet`, through Yet's SES — when Yet opens it to the company (`ses_allowed`) — or `own`.

### Read-Only

- `id` (String) The company's slug.
- `ses_allowed` (Boolean) Whether Yet's SES is open to the company at all.
