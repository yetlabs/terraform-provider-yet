# Resource: yet_settings_mail_subdomain

A subdomain of one of the company's domains, for the mail its systems send: on the mail server, in SES, and its records in Cloud's zone of its parent when the zone is there. The API sends only from a subdomain's addresses (`yet_settings_mail_send_email`), never from a domain its people's mailboxes are on.

!> **Warning:** Destroying it takes it from the mail server, its SES and the company, with its addresses.

## Example Usage

```terraform
# Order notices from a subdomain of their own, apart from the people's mail.
resource "yet_settings_mail_subdomain" "notices" {
  name = "avisos.acme.com.br"

  depends_on = [yet_settings_domain.br]
}
```
