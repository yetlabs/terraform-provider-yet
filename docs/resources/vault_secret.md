# Resource: yet_vault_secret

A secret of a vault's: its value goes to the vault, in the company's account, and is never read back — Yet answers its version alone. Changed, every application reading it is handed it anew. Destroyed, its bucket keeps its versions.

-> **Note:** Its value is in Terraform's state, as Terraform keeps what it is given: keep the state where secrets may be.

## Example Usage

```terraform
variable "auth_secret" {
  type      = string
  sensitive = true
}

resource "yet_vault_secret" "auth" {
  vault_id = yet_vault_vault.production.id
  name     = "AUTH_SECRET"
  note     = "Signs the sessions of the api."
  value    = var.auth_secret
}
```
