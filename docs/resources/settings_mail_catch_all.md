# Resource: yet_settings_mail_catch_all

Where mail to a domain's addresses that do not exist goes, instead of bouncing.

-> **Note:** Destroying it turns the catch-all off: such mail bounces again.

## Example Usage

```terraform
# Mail to any acme.dev address that does not exist reaches the list.
resource "yet_settings_mail_catch_all" "acme" {
  domain  = "acme.dev"
  address = yet_settings_mail_list.finance.address
}
```
