# Resource: yet_settings_mail_shared_mailbox

A shared mailbox: one of the company's, not of a person, that its members read beside their own, in Mail under "Shared with you" — read, archived or labelled by one is so for all of them. What the API sends from its address (`yet_settings_mail_send_email`) is kept in its Sent.

!> **Warning:** Destroying it, or changing its address, deletes it with every message in it.

## Example Usage

```terraform
# The orders the shop sends, and their answers, read by the people on them.
resource "yet_settings_mail_shared_mailbox" "orders" {
  address = "pedidos@${yet_settings_mail_subdomain.notices.name}"
  name    = "Pedidos"
  members = [
    yet_settings_person.ana.email,
  ]
}
```

## Schema

### Required

- `address` (String) Its address, lowercase, at one of the company's domains with mail: `pedidos@avisos.acme.com`.
- `members` (Set of String) The people in it, by address — only the company's — whole: those left out stop seeing it.

### Optional

- `name` (String) What Mail calls it: `Pedidos`. The address before the @ when not given.

### Read-Only

- `id` (String) The shared mailbox's address.
