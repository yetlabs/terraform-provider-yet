# Resource: yet_vault_grant

Lets an application read a vault's secrets, in the variables its `yet_cloud_application`'s `secret_env` names — on a runtime in a Kubernetes Secret beside it, on Lambda in its function's variables, and in its account's Parameter Store, under `/yet/<company>/<application id>/`, for it to read itself. Destroyed once it reads none of them.

## Example Usage

```terraform
# The api reads the vault's secrets: AUTH_SECRET, in its variables.
resource "yet_vault_grant" "api" {
  vault_id       = yet_vault_vault.production.id
  application_id = yet_cloud_application.api.id
}

resource "yet_cloud_application" "api" {
  namespace_id = yet_cloud_namespace.shop.id
  name         = "api"
  stages       = [yet_cloud_environment.production.id]
  secret_env = {
    AUTH_SECRET = yet_vault_secret.auth.id
  }
}
```
