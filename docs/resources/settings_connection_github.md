# Resource: yet_settings_connection_github

The company's GitHub, connected to Cloud with a token: what its runners — `yet_cloud_runner` — register with when they have no token of their own. GitHub is asked whose the token is as it is given, so a wrong one is refused at once. One per company.

!> **Warning:** A token takes the place of yet's GitHub App, if it was installed — and the App is what applications build from their repositories with. Destroyed, the connection goes, App and all. A company that builds from GitHub installs the App in Yet's apps, under Cloud's Connections, instead.

-> **Note:** The token is sealed in Cloud and never shown again: an imported connection has none in its state until it is set.

## Example Usage

```terraform
variable "github_token" {
  type      = string
  sensitive = true
}

# What the company's runners register with, when they have no token of their own.
resource "yet_settings_connection_github" "acme" {
  token = var.github_token
}
```
