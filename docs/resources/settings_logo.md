# Resource: yet_settings_logo

The company's logo on its sign-in page: a PNG, JPEG, WebP, GIF or SVG under 256 KB, from a file (`source`) or base64 (`content_base64`).

-> **Note:** Destroying it puts Yet's own mark back on the sign-in page.

## Example Usage

```terraform
# The sign-in page's logo, from a file next to the configuration.
resource "yet_settings_logo" "acme" {
  source = "${path.module}/logo.svg"
}
```

## Schema

### Optional

- `content_base64` (String) The image's bytes in base64: `filebase64("logo.png")`.
- `content_type` (String) The image's type — any of `image/png`, `image/jpeg`, `image/webp`, `image/gif`, `image/svg+xml`. Unset, it is told from the file's extension, or its bytes.
- `source` (String) The image's path: `${path.module}/logo.svg`.

### Read-Only

- `id` (String) The company's slug.
- `sha256` (String) The SHA-256 of the image's bytes, as Yet keeps them.

## Import

In Terraform v1.5.0 and later, with an [`import` block](https://developer.hashicorp.com/terraform/language/import):

```terraform
import {
  to = yet_settings_logo.acme
  id = "acme"
}
```

With [`terraform import`](https://developer.hashicorp.com/terraform/cli/commands/import):

```shell
# The company, by its slug. The next apply sets the logo from the configuration
# when its bytes differ.
terraform import yet_settings_logo.acme acme
```
