# Resource: yet_cloud_rack

A rack: a group of servers and runtimes under a name of the company's — of no one kind: where each server comes from (its `origin`) is the server's own, so one rack may hold machines of the company's and, as they arrive, an AWS account's or a GCP project's.

## Example Usage

```terraform
resource "yet_cloud_rack" "home" {
  name        = "Home Rack"
  description = "The machines in the office."
}
```
