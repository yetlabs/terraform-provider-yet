# Resource: yet_settings_domain_claim

A domain the company asks for. It is the company's once a TXT record at its root says `txt` — publish it with any DNS resource — and `yet_settings_domain` verifies it.

-> **Note:** A domain another company asked for and has not shown in a week can be asked for again. Once the domain is the company's, the claim has done its work: destroying it then changes nothing.

## Example Usage

```terraform
resource "yet_settings_domain_claim" "br" {
  name = "acme-br.example.com"
}

# Its TXT, wherever the domain's DNS is kept — here, in the company's Cloud.
resource "yet_cloud_dns_record" "proof" {
  zone_id = yet_cloud_dns_zone.br.id
  name    = "@"
  type    = "TXT"
  ttl     = 300
  values  = [yet_settings_domain_claim.br.txt]
}
```
