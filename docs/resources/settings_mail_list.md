# Resource: yet_settings_mail_list

A list: one address of the company's that delivers to several — its own people, or anyone outside.

## Example Usage

```terraform
resource "yet_settings_mail_list" "finance" {
  domain      = "acme.example.org"
  name        = "financeiro"
  description = "Invoices and receipts."
  recipients = [
    yet_settings_person.ana.email,
    "accounting@example.com",
  ]
}
```

## Schema

### Required

- `domain` (String) One of the company's domains with mail.
- `name` (String) The list before the @: `financeiro`.
- `recipients` (Set of String) The addresses it delivers to, whole: those left out stop receiving it.

### Optional

- `description` (String) What the list is for, as Settings shows it.

### Read-Only

- `address` (String) The list's address: `financeiro@acme.example.org`.
- `id` (String) The list's id, as the mail server has it.
