# Resource: yet_cloud_runtime

How things run on a server: k3s, Docker, or native. A k3s runtime goes behind a Cloudflare tunnel of its own by itself, when Cloud's edge is set — `tunnel` says otherwise.

-> **Note:** Opening or closing its tunnel is a Cloud admin's, and changes its `ingress`: its environments' records follow it.

## Example Usage

```terraform
resource "yet_cloud_runtime" "k3s" {
  name      = "box-k3s"
  stack     = "local:traefik+k3s"
  server_id = yet_cloud_server.box.id
}

# One for GitHub's runners only: its ingress off, so it takes no environment.
resource "yet_cloud_runtime" "ci" {
  name            = "box-ci"
  stack           = "local:traefik+k3s"
  server_id       = yet_cloud_server.box.id
  ingress_enabled = false
}
```

## Schema

### Required

- `name` (String) Its name: lowercase letters, digits and dashes, up to 32, starting with a letter.
- `server_id` (String) The server it runs on.
- `stack` (String) How it runs: `local:traefik+k3s`, `local:docker` or `local:native`.

### Optional

- `ingress` (String) The address its environments' records point at: an IP or a name. Its tunnel's while it has one.
- `ingress_enabled` (Boolean) Whether a k3s runtime's ingress is on: on unless set to `false` — for one that runs runners only. Off, it takes no environment and joins no pool; turned off or on, the agent makes its k3s again, its data kept — and not off while an environment runs there.
- `region` (String) A Lambda runtime's region (stack `aws:lambda`, on a serverless `yet_cloud_server`): where its functions run, in the server's account — one runtime a region; the account's own when left out. An environment may list several (`functions`), and each application's stage picks one (`stage_function`).
- `tunnel` (Boolean) Whether it is behind a Cloudflare tunnel of its own — its edge. A k3s runtime is, made while Cloud's edge is set, unless this says otherwise; only k3s runtimes have one, for now.

### Read-Only

- `id` (String) The ID of this resource.
- `pool_id` (String) The pool it is a member of, if any — set on yet_pool.
- `rack_id` (String) Its server's rack.
- `status` (String) How it stands, as Cloud shows it.
- `tunnel_id` (String) Its Cloudflare tunnel, when it has one.
