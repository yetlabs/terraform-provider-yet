# Resource: yet_cloud_database_attachment

An environment's database — `yet_cloud_database` — handed to an application on its stage there, in a variable. Its other stages are not handed it.

~> **Note:** The application must have a stage on the database's environment, and no other variable of that name — its own `env`, a database of its own, another attachment.

## Example Usage

```terraform
resource "yet_cloud_database" "ledger" {
  kind           = "overlite"
  name           = "ledger"
  environment_id = yet_cloud_environment.production.id
}

# The production ledger, handed to the API on its production stage.
resource "yet_cloud_database_attachment" "api_ledger" {
  application_id = yet_cloud_application.api.id
  database_id    = yet_cloud_database.ledger.id
  env_var        = "LEDGER_URL"
}
```
