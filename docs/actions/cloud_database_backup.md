# Action: yet_cloud_database_backup

Backs up a database now — one copy per stage it runs on — and waits for the copies to be taken.

-> **Note:** Copies are kept for an Overlite on a runtime of the company's. Its runtime's agent takes them at its next look.

## Example Usage

```terraform
resource "yet_cloud_database" "ledger" {
  kind           = "overlite"
  name           = "ledger"
  environment_id = yet_cloud_environment.production.id
}

action "yet_cloud_database_backup" "ledger" {
  config {
    database_id = yet_cloud_database.ledger.id
  }
}

# Run it by hand before a change that matters:
#   terraform apply -invoke action.yet_cloud_database_backup.ledger
```
