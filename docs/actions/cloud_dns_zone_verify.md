# Action: yet_cloud_dns_zone_verify

Asks a zone's domain for its nameservers again, now, rather than at Cloud's next look: right after its registrar was pointed at the zone's `nameservers`.

## Example Usage

```terraform
resource "yet_cloud_dns_zone" "acme" {
  name = "acme.example.org"
}

action "yet_cloud_dns_zone_verify" "acme" {
  config {
    zone_id = yet_cloud_dns_zone.acme.id
  }
}

# Once the registrar points at the zone's nameservers:
#   terraform apply -invoke action.yet_cloud_dns_zone_verify.acme
```
