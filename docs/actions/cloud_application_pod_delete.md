# Action: yet_cloud_application_pod_delete

Deletes one of an application's pods, on whichever runtime runs it: its deployment starts a fresh copy in its place — a restart of that one copy, the rest left running.

-> **Note:** It takes a developer's role in the pod's environment. The runtime's agent deletes the pod at its next look.

## Example Usage

```terraform
action "yet_cloud_application_pod_delete" "api" {
  config {
    application_id = yet_cloud_application.api.id
    pod            = "api-7d9f8-x2k4p"
  }
}

# Run it by hand, when one copy misbehaves; a fresh one takes its place:
#   terraform apply -invoke action.yet_cloud_application_pod_delete.api
```
