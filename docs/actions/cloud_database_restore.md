# Action: yet_cloud_database_restore

Restores one of a database's copies in its place, on the copy's stage — and waits for it to be back.

~> **Warning:** The database stops for a moment and starts again on the copy: what was written since is not in it. The file before is kept on its volume, `app.db.before-restore`, until the next restore.

## Example Usage

```terraform
action "yet_cloud_database_restore" "ledger" {
  config {
    database_id = yet_cloud_database.ledger.id
    backup_id   = "bk_1"
  }
}

# Run it by hand, once the copy is the one — looked into in its Studio first:
#   terraform apply -invoke action.yet_cloud_database_restore.ledger
```
