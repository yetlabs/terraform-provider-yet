# Action: yet_settings_mail_send_email

Sends an email from one of the company's subdomains' addresses (`yet_settings_mail_subdomain`), through the SES that subdomain sends through: a notice when something is made, say.

-> **Note:** Each run sends again. With `idempotency_key`, a run with a key already used answers the email it sent then, and sends nothing.

## Example Usage

```terraform
action "yet_settings_mail_send_email" "launched" {
  config {
    from    = "Acme <ops@${yet_settings_mail_subdomain.notices.name}>"
    to      = ["ana@acme-br.example.com"]
    subject = "The storefront is up"
    html    = "<p>${yet_cloud_application.api.name} runs in production.</p>"
    tags    = { kind = "launch" }

    # Sent once, however many times the action runs.
    idempotency_key = "storefront-launched"
  }
}

# Told by email as soon as the application is made.
resource "terraform_data" "launched" {
  input = yet_cloud_application.api.id

  lifecycle {
    action_trigger {
      events  = [after_create]
      actions = [action.yet_settings_mail_send_email.launched]
    }
  }
}

# Or by hand:
#   terraform apply -invoke action.yet_settings_mail_send_email.launched
```

### Required

- `from` (String) The sender, at a subdomain: `Acme <avisos@avisos.acme.example.com>` or the bare address.
- `subject` (String) The subject.
- `to` (List of String) Who it goes to; with `cc` and `bcc`, up to 50.

### Optional

- `attachments` (Attributes List) Files it carries, up to 10 MB in all. (see [below for nested schema](#nestedatt--attachments))
- `bcc` (List of String) Who receives a copy, unseen by the rest.
- `cc` (List of String) Who receives a copy.
- `headers` (Map of String) The message's own headers, by name, besides those the fields above write.
- `html` (String) The body as HTML; `html`, `text` or both.
- `idempotency_key` (String) A key of the caller's: sent again with it, it answers the same email instead of sending twice.
- `reply_to` (List of String) Where replies go, when not to `from`.
- `tags` (Map of String) SES's tags, by name, kept with its events: up to 10, letters, digits, `_` and `-`.
- `text` (String) The body as plain text.
