# Action: yet_cloud_application_build

Builds an application's branch as it is now — its latest commit — without waiting for a push: a release, deployed to its first stage once its runtime has built the image.

-> **Note:** The application is built from a repository on the company's GitHub, through yet's GitHub App; building deploys to its first stage, so it takes a developer's role there.

## Example Usage

```terraform
action "yet_cloud_application_build" "api" {
  config {
    application_id = yet_cloud_application.api.id
  }
}

# Built from its branch as soon as the application is made, not at the next push.
resource "terraform_data" "first_build" {
  input = yet_cloud_application.api.id

  lifecycle {
    action_trigger {
      events  = [after_create]
      actions = [action.yet_cloud_application_build.api]
    }
  }
}

# Or by hand:
#   terraform apply -invoke action.yet_cloud_application_build.api
```
