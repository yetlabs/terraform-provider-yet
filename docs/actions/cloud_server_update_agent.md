# Action: yet_cloud_server_update_agent

Asks a server's agent to update now, to Cloud's version, rather than at its own next try, half an hour after the one before: it does at its next check-ins. Only an agent behind Cloud is asked.

## Example Usage

```terraform
resource "yet_cloud_server" "nuc" {
  name = "nuc"
}

action "yet_cloud_server_update_agent" "nuc" {
  config {
    server_id = yet_cloud_server.nuc.id
  }
}

# Its agent behind Cloud, after a deploy:
#   terraform apply -invoke action.yet_cloud_server_update_agent.nuc
```
