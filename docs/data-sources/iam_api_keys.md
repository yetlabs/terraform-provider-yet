# Data Source: yet_iam_api_keys

Every API key the company's people hold — who, since when, last used when. Only each key's first characters are kept.

~> **Note:** Keys are made by each person, in Yet's Preferences — never with another key — and revoked there, or by an admin in Settings → IAM.

## Example Usage

```terraform
data "yet_iam_api_keys" "acme" {}

# Keys never used — candidates to revoke, in Settings → IAM.
output "unused_keys" {
  value = [for k in data.yet_iam_api_keys.acme.keys : "${k.email}: ${k.name}" if k.last_used_at == ""]
}
```
